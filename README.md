# 🤖 My First Chatbot

A simple chatbot built using **Python**, **NLTK**, and **PyTorch**. This project uses a **Neural Network** to train a model that can recognize user intents and generate appropriate responses.

This is my first chatbot project, developed as part of my journey in learning Python, Natural Language Processing (NLP), and Deep Learning.

## 🧠 How It Works

The chatbot uses a neural network-based approach to understand user input and predict the corresponding intent.

The general workflow consists of:

1. **Input Processing** – Receive and process the user's message.
2. **Tokenization** – Break the input sentence into individual words using NLTK.
3. **Feature Extraction** – Convert the processed text into numerical representations.
4. **Intent Classification** – Pass the input features into a trained neural network to predict the user's intent.
5. **Response Generation** – Select an appropriate response based on the predicted intent.
